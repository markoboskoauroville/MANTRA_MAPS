# MANTRA MAPS

Offline map files for **Mantra Trail**, kept here because they are needed in a valley and the
places they come from are not always up.

Each release holds one `.map` file: mapsforge format, which the app reads directly. Nothing here
is generated by this repository — the files are mirrored, with their source and licence named.

| release | file | from | licence |
|---|---|---|---|
| croatia-1 | openhiking-croatia.map | [OpenHiking](https://www.openhiking.eu) | map data © OpenStreetMap contributors (ODbL) |

The originals are made from OpenStreetMap data. The data is © OpenStreetMap contributors and is
available under the Open Database Licence. Mirroring is allowed; the attribution travels with it.
